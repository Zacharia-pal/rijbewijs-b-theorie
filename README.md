# Wegwijzer Rijbewijs B

Volledige theoriecursus voor het Belgische rijbewijs B, als een enkele webpagina.

**Online:** https://zacharia-pal.github.io/rijbewijs-b-theorie/

## Wat erin zit

- 32 lessen in acht delen, met leerdoelen, uitgewerkte verkeerssituaties en samenvattingen
- 116 verkeersborden, allemaal als SVG getekend
- 46 uitgewerkte illustraties
- een databank van 728 vragen waaruit elke reeks willekeurig getrokken wordt
- een bordentrainer
- oefenexamens met de puntentelling van GOCA: 50 vragen, slagen vanaf 41, zware fout kost 5 punten

## Losse oefenpagina's

De pagina herkent deze adressen en toont dan alleen die oefening:

| Adres | Wat je krijgt |
|---|---|
| `#oefen-m11` | tien willekeurige vragen over les 11 |
| `#examen` | een volledig oefenexamen van 50 vragen |
| `#borden` | de bordentrainer |

Die adressen zitten als QR-code in het cursusboek.

Bijgewerkt tot 14 september 2026. De nieuwe Code van de openbare weg treedt pas op 1 juni 2027 in werking; les 32 zet naast elkaar wat er dan verandert. Dit is een leermiddel en geen juridische bron.
